
# Education AI Chatbot

## Project Title
Building an Interactive AI Chatbot using Ollama

## Objective
To develop an educational chatbot using Python and a locally running Large Language Model.

## Technologies Used
- Python
- Ollama
- Llama 3.2 1B
- CSV for storing conversation records

## Features
1. Answers educational questions.
2. Supports continuous conversation.
3. Maintains conversation context during a session.
4. Saves questions and responses in CSV files.
5. Records timestamps and session IDs.
6. Supports Python, AI and DBMS-related questions.

## Execution
1. Install Ollama.
2. Download the model using `ollama pull llama3.2:1b`.
3. Install dependencies using `pip install ollama pandas jupyter`.
4. Run `python chatbot.py`.
5. Type questions and enter `exit` to stop.

## Output Files
- sample_questions.csv
- chat_history.csv
- responses.csv
- chatbot_logs.txt
